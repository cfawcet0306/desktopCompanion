A simple project made over a weekend to experiment with audio and visual tools in Java.

HOW TO USE:

1. Ensure that "silent.png" and "speak.png" are in "desktopCompanion/resources/imageFiles".
2. Ensure that all desired audio files are in a ".wav" format, and place them all in "desktopCompanion/resources/audioFiles".
3. Run "CompanionHandler" and it will now operate.

NOTES
1. There are starter files to use, so if you just wanna check if this works, by all means it should be ready out the box
2. The starter visuals have a white box. This is not because the application frame isn't transparent, it is because I didn't make a transparent background in MS paint.
